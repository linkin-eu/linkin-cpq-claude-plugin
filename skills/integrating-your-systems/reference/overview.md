## Operations

- `GET /public/v1/health` (get_health): The service is up, and on which model. Needs: nothing. Answers: 200 HealthDocument.
- `GET /customer/v1/assortment` (list_assortment): The customer's assortment: its own geometries, then the catalogue. Needs: query `soldToParty`; query `salesOrganization`; query `distributionChannel`; query `after` (optional); query `limit` (optional). Answers: 200 Assortment. Refuses: 400 INVALID_CURSOR, INVALID_REQUEST, UNKNOWN_SALES_AREA; 403 CUSTOMER_NOT_ALLOWED; 500 INTERNAL.
- `GET /customer/v1/materials` (list_materials): The materials a sales order can configure, in the customer's sales area. Needs: query `salesOrganization`; query `distributionChannel`; query `after` (optional); query `limit` (optional). Answers: 200 MaterialList; 304 unchanged since asked. Refuses: 400 INVALID_CURSOR, INVALID_REQUEST, UNKNOWN_SALES_AREA; 403 CUSTOMER_NOT_ALLOWED; 500 INTERNAL.
- `GET /customer/v1/materials/{material}` (describe_material): A material: its fields, as CT04, its class and its configuration profile define them. Needs: path `material`. Answers: 200 MaterialDefinition; 304 unchanged since asked. Refuses: 400 INVALID_REQUEST; 404 UNKNOWN_MATERIAL; 500 INTERNAL.
- `GET /customer/v1/tariff` (get_price_list): The price list of the customer's sales area. Needs: query `salesOrganization`; query `distributionChannel`. Answers: 200 TariffDocument; 304 unchanged since asked. Refuses: 400 INVALID_REQUEST, UNKNOWN_SALES_AREA; 403 CUSTOMER_NOT_ALLOWED; 500 INTERNAL.
- `POST /customer/v1/materials/{material}/configuration` (configure_item): Configure one profile: the screen. Needs: path `material`; body ConfigurationRequest (required: quantity, salesOrganization, distributionChannel). Answers: 200 ConfigurationDocument. Refuses: 400 INVALID_JSON, INVALID_QUANTITY, INVALID_REQUEST, MATERIAL_NOT_IN_SALES_AREA, UNKNOWN_CHARACTERISTIC, UNKNOWN_SALES_AREA, UNKNOWN_SOLD_TO_PARTY; 403 CUSTOMER_NOT_ALLOWED; 404 UNKNOWN_MATERIAL; 413 BODY_TOO_LARGE; 415 UNSUPPORTED_MEDIA_TYPE; 500 INTERNAL.
- `POST /customer/v1/value-help` (find_values): The values one field allows, within a configuration: F4. Needs: body ValueHelpRequest (required: material, characteristic, salesOrganization, distributionChannel). Answers: 200 ValueHelpList. Refuses: 400 INVALID_CURSOR, INVALID_JSON, INVALID_REQUEST, MATERIAL_NOT_IN_SALES_AREA, UNKNOWN_CHARACTERISTIC, UNKNOWN_MATERIAL, UNKNOWN_SALES_AREA; 403 CUSTOMER_NOT_ALLOWED; 413 BODY_TOO_LARGE; 415 UNSUPPORTED_MEDIA_TYPE; 500 INTERNAL.
- `POST /customer/v1/order` (evaluate_order): Price an order, as SAP's sales order simulation. Needs: body OrderRequest (required: salesOrganization, distributionChannel, items). Answers: 200 OrderDocument. Refuses: 400 ANSWER_TOO_LARGE, INVALID_JSON, INVALID_QUANTITY, INVALID_REQUEST, MIXED_SALES_AREA, TOO_MANY_ITEMS, UNKNOWN_SALES_AREA, UNKNOWN_SOLD_TO_PARTY; 403 CUSTOMER_NOT_ALLOWED; 413 BODY_TOO_LARGE; 415 UNSUPPORTED_MEDIA_TYPE; 500 INTERNAL; 503 DEADLINE_EXCEEDED.
- `POST /customer/v1/load-plan` (plan_load): Plan the trucks: how much fits, to size the order. Needs: body LoadPlanRequest (required: salesOrganization, distributionChannel, soldToParty). Answers: 200 LoadPlan. Refuses: 400 ANSWER_TOO_LARGE, INVALID_JSON, INVALID_QUANTITY, INVALID_REQUEST, MIXED_SALES_AREA, TOO_MANY_ITEMS, UNKNOWN_SALES_AREA, UNKNOWN_SOLD_TO_PARTY; 403 CUSTOMER_NOT_ALLOWED; 413 BODY_TOO_LARGE; 415 UNSUPPORTED_MEDIA_TYPE; 422 NOT_PLANNABLE; 500 INTERNAL; 503 DEADLINE_EXCEEDED.
- `GET /customer/v1/quotations` (list_quotations): The customer's quotations, newest first. Needs: query `soldToParty`; query `salesOrganization`; query `distributionChannel`; query `customerReference` (optional); query `number` (optional); query `status` (optional); query `limit` (optional); query `after` (optional). Answers: 200 QuotationHistory. Refuses: 400 INVALID_CURSOR, INVALID_REQUEST; 403 CUSTOMER_NOT_ALLOWED; 500 INTERNAL.
- `POST /customer/v1/quotations` (issue_quotation): Issue the order as a quotation. Needs: body QuotationRequest (required: salesOrganization, distributionChannel, soldToParty, items, expected). Answers: 201 QuotationLink. Refuses: 400 INVALID_JSON, INVALID_QUANTITY, INVALID_REQUEST, MIXED_SALES_AREA, TOO_MANY_ITEMS, UNKNOWN_SALES_AREA, UNKNOWN_SOLD_TO_PARTY; 403 CUSTOMER_NOT_ALLOWED; 413 BODY_TOO_LARGE; 415 UNSUPPORTED_MEDIA_TYPE; 422 NOT_ISSUABLE, ORDER_DIFFERS, PRICES_CHANGED; 500 INTERNAL; 503 DEADLINE_EXCEEDED.
- `GET /customer/v1/quotations/{id}` (get_quotation_page): An issued quotation, its summary page. Needs: path `id`. Answers: 200 text/html; 304 unchanged since asked. Refuses: 400 INVALID_REQUEST; 404; 410; 500 INTERNAL.
- `GET /customer/v1/quotations/{id}/details` (get_quotation_details_page): An issued quotation's details page. Needs: path `id`. Answers: 200 text/html; 304 unchanged since asked. Refuses: 400 INVALID_REQUEST; 404; 410; 500 INTERNAL.
- `GET /customer/v1/quotations/{id}/document` (get_quotation): An issued quotation as JSON. Needs: path `id`; query `limit` (optional); query `after` (optional). Answers: 200 IssuedDocument. Refuses: 400 ANSWER_TOO_LARGE, INVALID_CURSOR, INVALID_REQUEST; 404 UNKNOWN_QUOTATION; 500 INTERNAL.
- `GET /customer/v1/quotations/{id}/document/items` (get_quotation_items): An issued quotation's items in detail. Needs: path `id`; query `items` (optional); query `limit` (optional); query `after` (optional). Answers: 200 IssuedItems. Refuses: 400 ANSWER_TOO_LARGE, INVALID_CURSOR, INVALID_REQUEST, TOO_MANY_ITEMS; 404 UNKNOWN_QUOTATION; 410 QUOTATION_REVOKED; 500 INTERNAL.
- `POST /customer/v1/quotations/{id}/submit` (submit_quotation): Submit an issued quotation. Needs: path `id`; body SubmissionRequest (required: soldToParty, salesOrganization, distributionChannel). Answers: 200 QuotationLink. Refuses: 400 INVALID_JSON, INVALID_REQUEST; 404 UNKNOWN_QUOTATION; 410 QUOTATION_REVOKED; 413 BODY_TOO_LARGE; 415 UNSUPPORTED_MEDIA_TYPE; 422 NOT_SUBMITTABLE; 500 INTERNAL.
- `POST /customer/v1/quotations/{id}/revoke` (revoke_quotation): Revoke a draft quotation. Needs: path `id`; body RevocationRequest (required: soldToParty, salesOrganization, distributionChannel, reason). Answers: 200 QuotationLink. Refuses: 400 INVALID_JSON, INVALID_REQUEST; 404 UNKNOWN_QUOTATION; 413 BODY_TOO_LARGE; 415 UNSUPPORTED_MEDIA_TYPE; 422 NOT_REVOCABLE; 500 INTERNAL.
- `GET /customer/v1/inquiries` (list_inquiries): The customer's inquiries, newest first. Needs: query `soldToParty`; query `salesOrganization`; query `distributionChannel`; query `customerReference` (optional); query `number` (optional); query `status` (optional); query `limit` (optional); query `after` (optional). Answers: 200 InquiryHistory. Refuses: 400 INVALID_CURSOR, INVALID_REQUEST; 403 CUSTOMER_NOT_ALLOWED; 500 INTERNAL.
- `POST /customer/v1/inquiries` (issue_inquiry): Issue the order as an inquiry. Needs: body InquiryRequest (required: salesOrganization, distributionChannel, soldToParty, customerReference, items, expected). Answers: 201 QuotationLink. Refuses: 400 INVALID_JSON, INVALID_QUANTITY, INVALID_REQUEST, MIXED_SALES_AREA, TOO_MANY_ITEMS, UNKNOWN_SALES_AREA, UNKNOWN_SOLD_TO_PARTY; 403 CUSTOMER_NOT_ALLOWED; 413 BODY_TOO_LARGE; 415 UNSUPPORTED_MEDIA_TYPE; 422 NOT_ISSUABLE, ORDER_DIFFERS, PRICES_CHANGED; 429 TOO_MANY_INQUIRIES; 500 INTERNAL; 503 DEADLINE_EXCEEDED.
- `GET /customer/v1/inquiries/{id}` (get_inquiry_page): An issued inquiry, its summary page. Needs: path `id`. Answers: 200 text/html; 304 unchanged since asked. Refuses: 400 INVALID_REQUEST; 404; 410; 500 INTERNAL.
- `GET /customer/v1/inquiries/{id}/details` (get_inquiry_details_page): An issued inquiry's details page. Needs: path `id`. Answers: 200 text/html; 304 unchanged since asked. Refuses: 400 INVALID_REQUEST; 404; 410; 500 INTERNAL.
- `GET /customer/v1/inquiries/{id}/document` (get_inquiry): An issued inquiry as JSON. Needs: path `id`; query `limit` (optional); query `after` (optional). Answers: 200 IssuedDocument. Refuses: 400 ANSWER_TOO_LARGE, INVALID_CURSOR, INVALID_REQUEST; 404 UNKNOWN_INQUIRY; 500 INTERNAL.
